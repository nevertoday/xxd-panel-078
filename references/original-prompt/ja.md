# XXD Panel 078 オリジナルスタイル指示 · 日本語参考訳

アップロードした各写真を独立した上質なデザインポスターにし、複数写真を組み合わせず一枚ずつ出力します。全体は3:4縦位置で、上下二領域を厳密に同じ高さの1:1、各50%とします。

上部には元写真を残し、主体の同一性、構造、姿勢、実在感、自然な光と影、元の色彩の空気を保ちます。アート誌、独立出版物、展覧会画像の質感になる軽い上質な調整だけを行います。周囲の環境は自然に拡張できますが、主体を伸縮、歪曲、変更しません。

下部では、最も識別性の高い**主体、輪郭、構造、姿勢、物語上の関係**から重要な同一性だけを残し、精緻で抑制された線形図形へ概括します。建築、人物、動物、植物、器物、乗り物、自然景観のどれでも、高級植物画のような**繊細な描線、簡略輪郭、少量の構造細部**で再編し、写実的なトレースや複雑な挿絵にせず一目で認識できるようにします。

素材は**暖かなアイボリーのコットンアート紙＋空押し／レタープレス深圧＋シャンパンゴールド箔**です。主体図形は**柔らかなシャンパン金箔**で統一し、紙とともに深く内側へ押し込みます。金線は実在する凹溝の内部にあり、周囲には紙の圧縮、縁の微光、自然な圧力影が生じます。凸状エンボスや表面に貼った箔ではなく「内側への凹み」を強調します。少量の無インク空押しを静かな第二構造として加えられます。

構図は**ミニマル、均衡、十分な余白**を保ち、主体を唯一の視覚中心にします。輪郭に応じて中央または少し偏置し、尺度、正負形、細線の流れで優雅な秩序をつくります。余計な装飾を加えません。植物、波紋、建築曲線、軌跡など元写真に美しい構造があれば、ごく少数の金線へ簡略化し、主体から自然に延長して一つの標章的構図にします。

文字は少量だけ使い、主体、場所、感情、象徴から短いタイトルや微細注釈を抽出します。言語や情報形式は固定しません。**細く優雅で、古典彫刻の趣を少し持ちながら現代的比率を保つ編集書体**を使い、同じシャンパン金箔の深圧で図形と同時に紙へ押し込みます。後付け文字ではなく、一工程の高級印刷に見せます。

全体は**暖かなアイボリーコットン紙、深い凹圧、凹溝内のシャンパン金箔、細線画、見える紙繊維、微細な縁の光と圧力影**による控えめな高級感です。高級香水、花藝、宝飾、婚礼紙品、精品ブランドの視覚体系を思わせます。実在紙繊維、圧痕深度、金箔の繊細な反射、静かな余白を強調し、凸状箔、明るい黄金属、鏡面金、金属グラデーション、プラスチック浮彫、3D、複雑な多色画、過装飾、テンプレート感を避けます。
